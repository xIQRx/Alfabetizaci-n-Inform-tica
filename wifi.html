Configuracion del wi-fi

📝 Actividad práctica: Conectando tu equipo a la red Wi-Fi

  1. Abrir el menú de Configuración en el dispositivo.
  2. Seleccionar la opción Red e Internet → Wi-Fi.
  3. Activar el interruptor de Wi-Fi.
  4. Elegir la red disponible y escribir la contraseña.
  5. Verificar la conexión abriendo una página web o aplicación que requiera Internet.
